A single repository that carries my whole development setup between machines: shell
configuration, aliases, editor settings, and a bootstrap script that installs the
essentials and symlinks everything into place.

## What it does

- One command to provision a fresh machine.
- Sensible, documented defaults for shell and editor.
- Small, composable scripts instead of one giant install file.

## What I learned

Keeping configuration in version control turns "it works on my machine" into "it works
on any machine." A few of the tricks live in my [wiki](/wiki).
