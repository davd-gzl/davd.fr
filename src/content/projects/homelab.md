My homelab is where I try infrastructure ideas without cloud bills. It runs a handful
of self-hosted services in containers, with automated backups and basic monitoring.

## Highlights

- **Reproducible**: everything is declared as configuration, so I can rebuild from
  scratch.
- **Backed up**: scheduled, tested backups — a backup you haven't restored isn't a
  backup.
- **Observable**: lightweight metrics and alerts so I know when something breaks.

It's the best way I've found to learn operations: run real things, break them, fix
them. Notes from the journey are in the [wiki](/wiki).
